## How each part is kept current

- `meta/code-graph.json` and `meta/code-graph.md` are generated by `scripts/code_graph.py`. Regenerate with `uv run python scripts/code_graph.py --write`; run it without `--write` to check whether they are stale. `npm run check` runs that check, so a source change without a regenerated graph fails the checks. The graph is static: computed URLs and runtime behaviour are not shown.
- `entities/` and `concepts/` pages were written by `wiki-wasp-drone` from the source at commit `0a207b3`, with `file:line` citations. They are not regenerated automatically. After code changes, re-run the wiki drone in `update` mode for the affected files instead of hand-editing citations.
- `meta/2026-10-19-*-report.md` are the run reports for that pass, including skipped symbols and candidate decisions. Canonical ADRs live in `docs/adr/`.
